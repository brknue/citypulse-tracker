# CityPulse

Tracker for **small cities and towns worldwide**.

## Reality check
There are millions of named places on Earth (4M+ in some databases). This site does **not** claim to cover every single settlement with unique daily news. It provides:

- A curated, searchable catalog of notable small cities/towns across continents
- Individual city tracker pages (`track.html?city=slug`) — open many in browser tabs
- “Track This” + shared list via localStorage
- Region filters (Europe, Asia, Americas, Africa, Oceania)

## Pages
| File | Purpose |
|------|---------|
| `index.html` | Home + featured towns + regions |
| `track.html` | Individual city tracker |
| `catalog.html` | Full searchable catalog |

## Usage
Open `index.html` or `catalog.html` in a browser. Click any city to open its tracker in a new tab.

Built with plain HTML + Tailwind CDN.
